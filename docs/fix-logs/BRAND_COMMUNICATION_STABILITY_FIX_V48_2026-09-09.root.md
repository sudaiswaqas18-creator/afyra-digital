# Afyra Digital — Brand & Creative Communication Stability Fix V48

## Root cause
The intended V47 Brand Communication stylesheet was linked only in `src/renderer.tsx`. The real app HTML is generated by `src/index.tsx`, where V47 was not loaded. At the same time, many historical Home-02/Brand CSS patches were still loaded in production. The live route therefore used old conflicting layout rules while the newer React/GSAP markup expected V47 styling.

This mismatch explains the visible failures in the supplied screenshots:
- hero dashboard collapsing into a thin horizontal strip;
- Brand Communication strip items running together;
- feature/display layouts losing their card geometry;
- the central Afyra logo escaping its intended display card and becoming extremely large;
- scroll choreography running against incorrect element dimensions.

## V48 corrections
1. `src/index.tsx` now loads `brand-communication-stability-v48.css` as the final stylesheet.
2. The unused `src/renderer.tsx` is synchronized to the same final stylesheet.
3. Historical Brand/Home-02 route CSS files are no longer loaded and are removed from `public/static` in this artifact. This eliminates the conflicting `!important` cascade.
4. V48 is now the single route-specific CSS layer for `.sv-page.sv-layout-02`.
5. Hero composition, rating pill, dynamic word panel, dashboard front/back card, aspect ratio and scroll flip are constrained to stable dimensions.
6. The reference strip has proper horizontal rules, four corner nodes and spaced items.
7. Features intro and all five HTML/CSS animated display cards are bounded correctly, including the hub/logo visual.
8. Video frame, four nodes and click-to-play behavior remain intact.
9. Strategic Solution arc/glow and filter/cards remain intact.
10. The How It Works sticky runway is incorporated directly into V48, preserving the 01→02→03→04 GSAP scrub without depending on retired V36 CSS.
11. Pricing framing, watermark, four nodes and current approved Afyra program pricing remain intact.
12. FAQ two-column/accordion layout remains intact; contact copy typo corrected.
13. Responsive and reduced-motion rules remain included.
